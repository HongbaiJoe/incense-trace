# Xiangji V3 LaTeX package

V3 preserves the V2.5 scientific text, equations, tables, results, and bibliography. It replaces the seven manuscript figures with independently generated V3 artwork stored in `research/figures/v3`.

Main source:

```text
xiangji_source_stable_v3.tex
```

Compile from `research/submission/latex` with the same Unicode LaTeX toolchain used for V2.5. The source expects the editable V3 PDF figures under `../../figures/v3/` and uses `xiangji_v2_5_references.bib` together with `xiangji_cgir_v2_methods.bib`.
