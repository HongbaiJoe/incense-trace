# Xiangji V2.5 LaTeX package

`xiangji_source_stable_v2_5.tex` is the expanded graph-completion and weak-supervision manuscript. It uses `xiangji_v2_5_references.bib` together with `xiangji_cgir_v2_methods.bib`.

Compile from this directory with:

```bash
tectonic -X compile xiangji_source_stable_v2_5.tex
```

The compiled paper contains the 592-candidate extraction flow, 237-record model-facing corpus, nested weak-supervision experiment, source-stable graph equations, strong baselines, missingness tests, calibration, rarity and duplicate diagnostics, composition analysis, chemistry layer, case study, and research roadmap.
