- Amicro `ScrollReveal`: https://github.com/Subhan-code/Amicro--Micro-transitions-/blob/main/registry/ui/scroll/scroll-reveal.tsx . The 0.6 s duration, 30 px displacement, 0.95 scale and [0.16,1,0.3,1] easing are retained. Added client declaration and reduced-motion support. MIT license retained in `licenses/AMICRO.txt`.
- Dot Matrix `dotm-3x3-1`: https://github.com/zzzzshawn/matrix/blob/main/public/r/dotm-3x3-1.json . Four registry files are imported unchanged, used only during an actual save request. License retained in `licenses/DOTMATRIX.txt`; this is an application use, not redistribution as a standalone component library.
- Skiper UI: https://skiper-ui.com/docs/quick-start and free Apple play-button source https://skiper-ui.com/r/skiper3.json were inspected. The expanding 60–330 px playback panel does not fit the requested quiet incense cover, so it was not imported. No Pro code or paid license was used. It remains a named interaction reference, not a claimed implemented component.

No claim of a whole-site pixel-identical clone: the two imported components preserve their reference motion, while the layout follows the user's explicit left/right brief. Chinese content, prediction logic and scientific records remain Xiangji's own.
